# English Books — Sumário de sites (Bootstrap)

Este projeto usa apenas HTML e CSS com Bootstrap. Coloque sua imagem do ícone em `assets/icon.png`.

Editar links
- Abra `index.html` e altere os links dentro da grid para os seus sites.

Visualizar localmente

```
# com Python 3
python3 -m http.server

# com npm (instale serve: npm i -g serve)
serve .
```

Se quiser, posso:
- substituir os `href` pelos seus links reais
- importar a imagem que você anexou como `assets/icon.png`
- publicar no GitHub Pages
# English Books — Sumário de sites


Edite `index.html` para atualizar os links diretamente no HTML.

Para abrir localmente, basta abrir `index.html` no navegador ou rodar um servidor estático:

```
# com Python 3
python3 -m http.server

# com npm (instale serve: npm i -g serve)
serve .
```

Se quiser, eu posso:
- adicionar os seus links reais
- melhorar o layout (cards, descrições, ícones)
- gerar uma versão pronta para deploy (GitHub Pages)
